# Temperature Converter

## OASIS INFOBYTE – Web Development and Designing

### Level 1 – Task 3

A simple and responsive Temperature Converter web application built using HTML5, CSS3, and Vanilla JavaScript.

## Project Overview

This project allows users to enter a temperature and select the input unit. The application converts the temperature into Celsius, Fahrenheit, and Kelvin.

## Features

- Convert Celsius to Fahrenheit and Kelvin
- Convert Fahrenheit to Celsius and Kelvin
- Convert Kelvin to Celsius and Fahrenheit
- Numeric input validation
- Empty input validation
- Absolute-zero validation
- Clear error messages
- Responsive and centered user interface
- Clean and modern design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Temperature Conversion Formulas

### Celsius

- Fahrenheit = (Celsius × 9/5) + 32
- Kelvin = Celsius + 273.15

### Fahrenheit

- Celsius = (Fahrenheit − 32) × 5/9
- Kelvin = Celsius + 273.15

### Kelvin

- Celsius = Kelvin − 273.15
- Fahrenheit = (Celsius × 9/5) + 32

## Validation

The application checks for:

- Empty temperature input
- Invalid temperature values
- Temperatures below absolute zero

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Enter a temperature.
5. Select the input unit.
6. Click **Convert Temperature**.
